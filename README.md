# مستندات پی‌را (PayRa Docs)

یک وب‌سایت مستندات فارسی و راست‌چین برای راهنمای استفاده از PayRa؛ با پوستهٔ روشن/تیره، جست‌وجوی داخلی، فهرست بخش‌ها و طراحی واکنش‌گرا.

## اجرا
فایل `index.html` را مستقیم در مرورگر باز کنید. نیازی به نصب پکیج یا build نیست.

## سفارشی‌سازی
- رنگ‌ها و تم‌ها در متغیرهای CSS ابتدای فایل تعریف شده‌اند.
- محتوای مستندات داخل تگ‌های `section.doc-section` قرار دارد.
- برای تغییر نام برند یا فوتر، عبارت‌های `PayRa` و `MTA · PAYRA DOCS` را جست‌وجو کنید.

## یادداشت دقت
این راهنما قابلیت‌های شناخته‌شده را مستند می‌کند و از فرض‌کردن جزئیات تأییدنشدهٔ نسخهٔ نصب‌شده پرهیز دارد. قبل از انتشار نهایی، نام دکمه‌ها، نقش‌ها و رفتارهای دقیق را با نسخهٔ عملیاتی PayRa تطبیق دهید.
